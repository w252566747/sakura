# Sakura Editor Curl 8.0 設定パック（非公式・カスタム）

対象: Sakura Editor 2.4.3.7173 GHA 32bit / 基準ソース fe1a4a281c6e6bec2a1a1bc39059fe7424bb5075。
Sakura Editor 本体のソース変更や実行ファイル置換はありません。背景色は Sakura 標準のアイボリー（RGB `#FFFBF0`）を使用します。元プロジェクトの Zlib ライセンスを維持し、公式配布物ではないカスタム設定であることを明示します。

## ファイル

- `Curl8.ini`: タイプ別設定の正規インポート形式。キーワード10分類、コメント、文字列、数値、配色、拡張子、キーワードからの補完設定を含みます。
- `Curl8.rkw`: 同じ横ハイフン識別子の独立インポート用。タイプINIにも埋め込んであります。INIをインポートした場合、別途RKWを再インポートしないでください。
- `Curl8.col`: Sakura標準のVer3カラー形式。色設定を単独で取り込む場合に使います。
- `Curl8_*.kwd`: Sakura標準キーワード定義ファイル。INIと同じフォルダーに置いてください。
- `Curl8_Autocomplete.txt`: 入力補完辞書（1行1候補）。標準設定では強調キーワードから補完します。任意で `支援` タブの単語ファイルにこの辞書を指定できます。
- `Curl8_sample.scurl`: 動作確認用のCurl断片。

## 安全な導入手順（日文メニュー）

1. 先にこのフォルダーを丸ごと任意の場所へコピーします。ファイル名と同じフォルダー内配置を保ってください。
2. Sakura Editorで `設定(O)` → `タイプ別設定一覧(Y)` を開きます。
3. リストの `インポート(I)` から `Curl8.ini` を選択します。初回は確認画面の `新規追加(&A)` を選びます。
4. 旧版の `Curl 8.0` が既にある場合は、一覧でそのタイプを選択してからインポートし、確認画面の2つ目の選択肢（`Curl 8.0`）を選んで既存タイプを更新します。`新規追加(&A)` のままだと重複タイプが作られます。色選択の先頭 `--そのままインポート--` を選び、INI内の配色と背景色を適用します。
5. `.kwd` が読み込まれた旨を確認します。インポート時にINIと同じフォルダーから相対ファイル名を解決します。
6. タイプ別設定一覧で `Curl 8.0` を選択し、`設定変更` → `スクリーン` で拡張子を確認します。Windows既定アプリ連携のチェック項目は変更しません。
7. `Curl8_sample.scurl` を開き、必要ならタイプ別設定一覧で `Curl 8.0` をダブルクリックして一時適用します。色分けと入力補完コマンドを確認します。補完は標準で強調キーワードから候補を出します。独立辞書を使う場合は `Curl8_Autocomplete.txt` のフルパスをタイプ設定の `支援` タブで指定してください。

取り消す場合は一覧から追加した `Curl 8.0` タイプだけを選んで削除します。設定変更後の `sakura.ini` からそのタイプは除かれます。

## 形式と制限

設定は対象ソースの `CImpExpType` / `CShareData_IO::ShareData_IO_Type_One` が扱う ` タイプ別設定 Ver1`、`[Info]`、`[Types]`、`[TypeEx]` 形式です。`vStructureVersion=182` は指定コミットの `N_SHAREDATA_VERSION` です。各キーワードセットは `[TypeEx]` から同梱 `.kwd` を相対参照します。

横ハイフン語は通常KWD検索の単語文字規則に含まれないため、BREGEXP互換正規表現で識別子境界つきにしています。正規表現キーワード機能はSakura側の正規表現ライブラリ（Bregonig/Bregexp）に依存します。公式ヘルプでは通常のフルパッケージに同梱とされています。別ランタイムやサービスは追加しません。

Sakuraネイティブのコメントフィールドで `||` 行コメントと `|# ... #|` ブロックコメントを扱います。単行の `|tag#...#tag|` は補助正規表現で色付けし、開始タグと終了タグの一致も確認します。複数行コメント・長さ指定コメントの構文状態管理はできません。正規表現色付けは文字列内部の無効化を完全には追跡できず、入れ子コメントも解析しません。Curl逐語文字列/特殊リテラルの全変種も標準文字列設定だけでは区別できません。

キーワード辞書は公式RTE 8.0ガイドとAPI名から作成した実用コア語彙です。RTEの全APIクラス/メンバーを網羅する巨大な自動抽出リストとは主張しません。API増分は各 `.kwd` に追記できます。

この設定はSakuraのファイルタイプ判定で `curl,dcurl,mcurl,scurl,xcurl,pcurl` を登録します。`.cprj` はCurl IDEのプロジェクト管理ファイルでありCurlソースコードではないため対象外です。これはSakura内部の拡張子判定だけで、Windowsの既定アプリ/シェル関連付けは変更しません。
